# 📚 คลังชีตสรุป ต้นน้ำ

เว็บรวมชีตสรุปบทเรียน ม.1 แยกตามวิชา เปิดอ่านบนมือถือหรือดาวน์โหลดเก็บไว้ได้

🔗 **ที่อยู่เว็บ:** https://hleeohm-art.github.io/tonnam-sheets/

การเพิ่มชีตใหม่**ไม่ต้องแก้โค้ดเลย** แค่อัปโหลดไฟล์ PDF แล้วเว็บจะอัปเดตรายการเอง

---

## ✅ ตั้งค่าครั้งแรก (ทำครั้งเดียวจบ)

1. เปิดหน้า repository นี้บน GitHub
2. กดแท็บ **Settings** (รูปเฟือง ⚙️ ด้านบน)
3. เมนูด้านซ้าย กด **Pages**
4. ตรงหัวข้อ **Build and deployment** → ช่อง **Source** เลือก **GitHub Actions**
5. เสร็จแล้ว! ต่อไปทุกครั้งที่อัปโหลดไฟล์ เว็บจะอัปเดตเอง

> ถ้าเพิ่งตั้งค่าเสร็จแต่เว็บยังไม่ขึ้น ให้ไปที่แท็บ **Actions** → เลือก **อัปเดตเว็บคลังชีต** ทางซ้าย → กดปุ่ม **Run workflow** → กด **Run workflow** สีเขียวอีกครั้ง

---

## ➕ วิธีเพิ่มชีตใหม่ (ทีละขั้น)

### ขั้นที่ 1: ตั้งชื่อไฟล์ให้อ่านง่าย

ชื่อไฟล์จะกลายเป็นชื่อชีตบนเว็บ ตั้งชื่อเป็นภาษาไทยได้เลย

- ใช้ `-` หรือ `_` แทนการเว้นวรรค → บนเว็บจะแสดงเป็นช่องว่างให้อัตโนมัติ
- ไม่ต้องสนใจ `.pdf` ท้ายชื่อ เว็บจะตัดออกให้

| ชื่อไฟล์ | บนเว็บจะแสดงเป็น |
|---|---|
| `เซลล์ของสิ่งมีชีวิต.pdf` | เซลล์ของสิ่งมีชีวิต |
| `จำนวนเต็ม_บทที่-1.pdf` | จำนวนเต็ม บทที่ 1 |
| `Tenses-สรุปครบ.pdf` | Tenses สรุปครบ |

💡 ชีตในแต่ละวิชาจะเรียงตามชื่อ ก–ฮ และตัวเลข (บทที่ 1, 2, 3 … 10)

### ขั้นที่ 2: เข้าโฟลเดอร์ของวิชา

ในหน้า repository กดเข้าโฟลเดอร์ **`sheets`** แล้วเลือกโฟลเดอร์ของวิชา

| วิชา | โฟลเดอร์ |
|---|---|
| 🔬 วิทยาศาสตร์ | `sheets/science` |
| 📐 คณิตศาสตร์ | `sheets/math` |
| 🔤 ภาษาอังกฤษ | `sheets/english` |
| 🌏 สังคมศึกษา | `sheets/social` |
| 📖 ภาษาไทย | `sheets/thai` |
| 📦 อื่นๆ | `sheets/other` |

### ขั้นที่ 3: อัปโหลดไฟล์

1. อยู่ในโฟลเดอร์วิชาแล้ว กดปุ่ม **Add file** (มุมขวาบน) → เลือก **Upload files**
2. ลากไฟล์ PDF มาวาง หรือกด **choose your files** เพื่อเลือกไฟล์ (เลือกได้หลายไฟล์พร้อมกัน)
3. เลื่อนลงล่าง กดปุ่มสีเขียว **Commit changes**

> 📱 ใช้มือถือ: เปิดเว็บ github.com ในเบราว์เซอร์ (ไม่ใช่แอป GitHub) แล้วกด **Add file → Upload files** ได้เหมือนกัน

### ขั้นที่ 4: รอประมาณ 1–2 นาที

GitHub จะสร้างรายการชีตใหม่และอัปเดตเว็บให้เอง

- ดูสถานะได้ที่แท็บ **Actions** 🟡 = กำลังทำ, ✅ = เสร็จแล้ว, ❌ = มีปัญหา
- เปิดเว็บแล้วยังไม่เห็นชีตใหม่? ลองรีเฟรชหน้าเว็บ
- ชีตที่เพิ่งอัปโหลดภายใน 14 วันจะมีป้าย **ใหม่** สีส้ม

---

## ✏️ แก้ไข / ลบ / เปลี่ยนชื่อชีต

- **ลบชีต:** กดเข้าไปที่ไฟล์ → กดปุ่ม **…** มุมขวาบน → **Delete file** → **Commit changes**
- **เปลี่ยนชื่อชีต:** ลบไฟล์เดิม แล้วอัปโหลดไฟล์ใหม่ที่ตั้งชื่อใหม่
- **อัปเดตเนื้อหาชีต:** อัปโหลดไฟล์ใหม่**ชื่อเดิม**ในโฟลเดอร์เดิม ไฟล์จะถูกแทนที่

ทุกครั้งเว็บจะอัปเดตเองภายใน 1–2 นาทีเช่นกัน

## ❓ ปัญหาที่พบบ่อย

**อัปโหลดแล้วชีตไม่ขึ้นเว็บ**
- ตรวจว่าไฟล์ลงท้ายด้วย `.pdf` และอยู่ในโฟลเดอร์ `sheets/...`
- ดูแท็บ **Actions** ว่ามี ❌ ไหม ถ้ามี กดเข้าไปแล้วกด **Re-run all jobs**

**ไฟล์ใหญ่เกินไปอัปโหลดไม่ได้**
- อัปโหลดผ่านหน้าเว็บได้ไฟล์ละไม่เกิน 25 MB ลองบีบอัด PDF ก่อน (ค้นคำว่า "compress pdf")

**ชีตไปอยู่หมวด "อื่นๆ" ทั้งที่ไม่ได้ตั้งใจ**
- แปลว่าไฟล์ไม่ได้อยู่ในโฟลเดอร์วิชาที่ถูกต้อง ย้ายไฟล์ไปโฟลเดอร์ที่ถูก (ลบแล้วอัปโหลดใหม่)

**ในโฟลเดอร์มีไฟล์ `README.md`**
- ไม่ต้องลบ ไฟล์นี้ช่วยให้โฟลเดอร์ยังอยู่แม้ยังไม่มีชีต

## 🛠️ สำหรับคนที่เขียนโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `assets/app.js`, `assets/style.css` | หน้าแรก: รายการชีต ค้นหา กรองตามวิชา |
| `viewer.html`, `assets/viewer.js` | หน้าเปิดอ่าน PDF (ใช้ pdf.js ใน `assets/pdfjs/` จึงเปิดบน Android ได้โดยไม่ต้องดาวน์โหลด) |
| `scripts/build-index.mjs` | อ่านไฟล์ใน `sheets/` แล้วสร้าง `sheets.json` (ตั้งค่ารายชื่อวิชา/ไอคอนได้ที่นี่) |
| `.github/workflows/deploy.yml` | รันสคริปต์ด้านบนแล้วเผยแพร่เว็บขึ้น GitHub Pages ทุกครั้งที่ push เข้า `main` |

ลองในเครื่อง:

```bash
node scripts/build-index.mjs
python3 -m http.server 8000
# เปิด http://localhost:8000
```

`sheets.json` ถูกสร้างใหม่ทุกครั้งตอน deploy จึงไม่เก็บไว้ใน git
